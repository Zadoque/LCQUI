\subsection{UI (Seção 8 UI-03)}

Componentes criados para gestão de Locais conforme S8 UI-03:
\begin{itemize}
  \item \path{frontend/src/components/patrimonio/NovaLocalModal.tsx}: modal CRIAR/EDITAR com campos prédio (\texttt{maxLength=30}), andar (\texttt{maxLength=10}, texto livre para térreo/subsolo), sala (\texttt{maxLength=30}); \texttt{trim()} e rejeição de vazios no cliente; M7 via \texttt{obterIntencaoPersistida}; callable \texttt{gerenciarLocal}; erro \texttt{already-exists} mapeado para banner no campo; correção crítica M7: \texttt{limparIntencao(sessionStorage, CHAVE\_INTENCAO\_LOCAL)} após sucesso evita replay silencioso que mascarava duplicatas em testes E2E; a11y (\texttt{role=dialog}, \texttt{aria-modal}, foco inicial, Escape); \texttt{data-testid}s para testabilidade.
  \item \path{frontend/src/components/patrimonio/ListaLocais.tsx}: \texttt{onSnapshot} coleção \texttt{Local} ordenada por \texttt{predio}; 5 estados explícitos (loading, permissionDenied, error, stale via \texttt{metadata.fromCache}, empty); modos listagem|seleção; \texttt{testIdPrefix} para escopar seletores quando usado dentro do \texttt{ModalNovoBem}.

  \item Integração em \path{frontend/src/components/patrimonio/ModaisPatrimonio.tsx}: \texttt{ModalNovoBem} contém seletor de Local via \texttt{ListaLocais} modo seleção + \texttt{NovaLocalModal} como etapa interna; \texttt{onSucesso(id)} seleciona o local recém-criado no formulário de origem.
\end{itemize}
